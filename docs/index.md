1. まずは [はじめての使い方](./getting-started.md) を読む
2. 次に [画面ガイド](./page-guide.md) で各ページの役割を確認する
3. ステージを 1 つ選んで脆弱版と修正版を見比べる
4. 分からない言葉があれば [やさしい解説ページ](./explanations.md) を見る
5. 詰まったら [ヒントページ](./hints.md) を見る
