# Security Practice Arcade Docs

Security Practice Arcade の利用手順と、各ステージをどう見ればよいかをまとめたドキュメントです。

## このドキュメントで分かること

- ローカルでの起動手順
- デモアカウント
- ステージごとの練習の進め方
- 管理画面の使い方
- リセット方法

## 入口

- [Practice Guide](./practice-guide.md)

## 対象サービス

- アプリ本体: `src/`
- GitHub repository: `NiheiKeita/security-practice`
- 公開先想定: `https://niheikeita.github.io/security-practice/`

## 使い方の流れ

1. アプリを起動する
2. デモアカウントでログインする
3. ステージを 1 つ選ぶ
4. 先に脆弱版を見る
5. 次に修正版を見て差分を確認する
6. JSON パネルとランキングも合わせて確認する
